# [Game Name] – English Translation Patch

This is a fan-made English translation patch for the classic Japanese visual novel **[Game Name]**.  
The patch replaces the original game script with translated CSV files – **no game code or assets are included**.

## 📦 What's inside
- `datascn.tac/` – folder containing all translated game scripts (CSV files)
- `NOTE.docx` – translator's notes, explanations, and technical details about the patch

## 🎮 Installation
1. **Own a legitimate copy** of the original Japanese game.
2. Copy the `datascn.tac` folder into the game's installation directory, overwriting the existing folder (backup first if needed).
3. Launch the game – the text should now appear in English.

> ⚠️ *If your game expects a single `datascn.tac` file instead of a folder, please read `NOTE.docx` for additional instructions.*
